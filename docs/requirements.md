# 项目需求文档 — SteadyHaven

## 项目概述

一款极简饮食记录 iOS App，纯本地存储，无需网络。用户可记录每日饮食的营养数据，查看今日和历史汇总。

## 核心功能

### 1. 今日饮食记录
- 展示当日总摄入热量（大号字体）及蛋白质、碳水、脂肪、钠总量
- 列表展示当天所有记录，可点击展开查看营养素详情
- 左滑删除记录（需确认）
- 右下角浮动"+"按钮添加记录

### 2. 添加饮食记录（Sheet）
- 食物名称输入
- 餐别选择：早餐 / 午餐 / 晚餐 / 加餐 / 无
- 每100g(ml)基准营养输入：热量、蛋白质、碳水、脂肪、钠
- 实际食用量 + 单位（g / ml），基准单位跟随食用量单位
- 实时预览计算后的总热量
- 点击"添加"写入数据库并刷新

### 3. 历史记录
- DatePicker 选择日期（默认今天）
- 显示选中日期的汇总卡片和记录列表
- 只读模式，不可编辑或删除

## 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| date | Date | 记录日期 |
| mealType | String? | 餐别（可为 nil） |
| foodName | String | 食物名称 |
| amount | Double | 实际食用量 |
| unit | String | 单位（g / ml） |
| calories | Double | 每100g(ml) 热量 |
| protein | Double | 每100g(ml) 蛋白质 |
| carbs | Double | 每100g(ml) 碳水 |
| fat | Double | 每100g(ml) 脂肪 |
| sodium | Double | 每100g(ml) 钠 |

**计算公式**：总营养 = 每100g(ml) 基准值 × (实际食用量 / 100)

## 非功能需求
- iOS 17+，SwiftUI + SwiftData
- 纯本地存储，无网络请求
- 淡蓝色简约风格
- SF Pro 字体
